# 🔐 Sistema de Login em Python
Sistema completo de autenticação desenvolvido em Python com interface gráfica Tkinter e banco de dados SQLite.

## ✨ Funcionalidades

- ✅ Interface gráfica moderna com Tkinter
- ✅ Cadastro de usuários com validação
- ✅ Login seguro com verificação em banco de dados
- ✅ Senhas criptografadas com bcrypt
- ✅ Navegação entre telas (Login ↔ Cadastro)
- ✅ Validação em tempo real
- ✅ Mensagens de erro/sucesso
- ✅ Banco de dados SQLite integrado

🔐 Segurança
Este sistema utiliza criptografia de senhas com *bcrypt*, garantindo que:
- As senhas não são armazenadas em texto puro  
- Cada senha possui proteção contra ataques  
- O sistema segue boas práticas de segurança
